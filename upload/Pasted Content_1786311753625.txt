Then, at the end of evaluation, it interpolates MG and EG based on the game phase:

```
CLASS BoardNavigator:
    FUNCTION __init__(pgn_string_or_fen):
        IF input is FEN:
            INIT board with FEN
            SET mode = SINGLE_POSITION
        ELSE IF input is PGN:
            PARSE PGN using chess.pgn.read_game
            RAISE InvalidPGNError IF game is None
            INIT board to root starting position
            SET mode = FULL_GAME
            LOAD all mainline moves into list

    FUNCTION get_ply_state(ply_index):

        INIT move_history = []

            FETCH move at index i
            RECORD move.uci() into move_history
            PUSH move to board

            current_move = move_history[ply_index - 1] IF ply_index > 0 ELSE None,
            move_number = (ply_index // 2) + 1,
            turn_color = board.turn,
            fen_before = board_before.fen(),
            fen_after = board.fen()
        )
```

```
FUNCTION parse_stockfish_score(uci_score_obj, current_ply):
    IF uci_score_obj.is_mate():
        moves_to_mate = uci_score_obj.mate()
        IF moves_to_mate > 0:
            normalized_cp = 10000 - (moves_to_mate * 10) - current_ply
        ELSE:
            normalized_cp = -10000 - (moves_to_mate * 10) + current_ply
        RETURN StockfishEvalModel(
            eval_type="mate",
            value=moves_to_mate,
            normalized_cp=normalized_cp,
            win_chance=1.0 IF moves_to_mate > 0 ELSE 0.0
        )
    ELSE:
        cp_val = uci_score_obj.score()
        # Win chance formula based on lichess/Stockfish centipawn conversion
        win_chance = 1 / (1 + 10 ** (-cp_val / 400.0))
        RETURN StockfishEvalModel(
            eval_type="cp",
            value=cp_val,
            normalized_cp=cp_val,
            win_chance=win_chance
        )

FUNCTION analyze_position(board, depth=20, multipv=3):

    RETURN List[MovePVModel] ordered by multipv_index (1, 2, 3)
```

## 7. LAYER 2: SYMBOLIC FEATURE & THREAT EXTRACTOR

This module is the core truth engine for tactics and positional features. It must be 100% deterministic using `python-chess`.

### 7.1 Static Exchange Evaluation (SEE) Algorithm
The system must calculate `SEE` for captures to determine if an exchange is winning, equal, or a material blunder.

```
FUNCTION calculate_see(board, move):
    # Uses python-chess built-in board.see(move)
    # Returns net material gain in centipawns
    see_value = board.see(move)
    is_winning_capture = (see_value >= 0)
    RETURN see_value, is_winning_capture
```

### 7.2 Null-Move Threat Detection Algorithm
To find exact, concrete threats created by a move $M$, the extractor must play $M$, execute a Null-Move (pass turn), and check what winning captures exist.

```
FUNCTION detect_concrete_threats(board_before, move):
    board = board_before.copy()
    board.push(move)  # Play the move
    
    threats_list = []
    
    # Null Move is illegal if player is in check
    IF board.is_check():
        RETURN threats_list
        
    board.push(chess.Move.null())  # Pass the opponent's turn
    
    FOR EACH legal_move IN board.legal_moves:
        IF board.is_capture(legal_move):
            see_value = board.see(legal_move)
            IF see_value >= 0:  # Only count winning/equal threats
                target_sq = legal_move.to_square
                target_piece = board.piece_at(target_sq)
                IF target_piece IS NOT NONE:
                    threats_list.append(ConcreteThreatModel(
                        threat_move_san = board.san(legal_move),
                        threat_move_uci = legal_move.uci(),
                        target_piece = target_piece.piece_type,
                        target_square = square_name(target_sq),
                        net_gain_cp = see_value,
                        is_winning_capture = (see_value > 0)
                    ))
                    
    board.pop()  # Pop null move
    board.pop()  # Pop player move
    
    # Deduplicate threats by target square, keep highest gain
    DEDUPLICATE threats_list BY target_square KEEP MAX net_gain_cp
    RETURN threats_list
```

### 7.3 Outpost Detection Algorithm
A square $S$ is an **Outpost** if:
1. $S$ is on Rank 4, 5, or 6 (for White) or Rank 3, 4, or 5 (for Black).
2. $S$ is defended by a friendly Pawn.
3. $S$ cannot be attacked by an enemy Pawn now or on adjacent files in the future.

```
FUNCTION is_outpost_square(board, square, color):
    rank = square_rank(square)
    file = square_file(square)
    
    # Rank Restrictions
    IF color == WHITE AND rank NOT IN [3, 4, 5]: RETURN False  # 0-indexed: 3=Rank 4
    IF color == BLACK AND rank NOT IN [2, 3, 4]: RETURN False  # 0-indexed: 4=Rank 5
    
    # Check friendly pawn support
    pawn_attackers = board.attackers(color, square)
    has_pawn_support = ANY(board.piece_at(sq).piece_type == PAWN FOR sq IN pawn_attackers)
    IF NOT has_pawn_support: RETURN False
    
    # Check enemy pawn attack potential (current or future)
    enemy_color = NOT color
    adjacent_files = [file - 1, file + 1] FILTERED BY valid_files (0..7)
    enemy_pawns = board.pieces(PAWN, enemy_color)
    
    FOR sq IN enemy_pawns:
        IF square_file(sq) IN adjacent_files:
            e_rank = square_rank(sq)
            IF color == WHITE AND e_rank >= rank: RETURN False  # Pawn can attack or passed
            IF color == BLACK AND e_rank <= rank: RETURN False
            
    RETURN True
```

### 7.4 Center Control & Open File Algorithms
- **Center Control Delta:** Calculate total attacks on $d4, d5, e4, e5$ by `board.is_attacked_by(color, square)` before and after the move.
- **Open File Control:** A file is **Open** if it contains 0 Pawns of either color. A file is **Semi-Open** if it contains 0 friendly Pawns and $\ge 1$ enemy Pawn.

## 8. LAYER 3: GAME MEMORY STACK & NARRATIVE STATE TRACKER

### 8.1 Purpose & State Preservation
The Game Memory Stack accumulates narrative state move-by-move. It prevents the system from evaluating moves in isolation, allowing explanations to reference past sacrifices, ongoing pawn weaknesses, and recent momentum.

### 8.2 State Update Algorithm

```
CLASS GameMemoryStack:
    FUNCTION __init__():
        self.persistent_imbalances = SET()
        self.key_past_events = LIST()
        self.recent_moves_fifo = QUEUE(max_size=3)

    FUNCTION process_ply(ply_index, move_san, fen_before, fen_after, eval_delta_cp, see_score, move_analysis):
        # 1. Update Recent Moves Buffer
        self.recent_moves_fifo.append(move_san)
        
        # 2. Detect Sacrifice Event
        IF move_analysis.is_capture AND see_score < -150 AND eval_delta_cp > -50:
            self.key_past_events.append(HistoricEventModel(
                move_number = (ply_index // 2) + 1,
                ply = ply_index,
                player_color = board.turn,
                move_san = move_san,
                event_type = "material_sacrifice",
                description = f"Sacrificed {move_analysis.captured_piece} on {move_san}",
                eval_delta_cp = eval_delta_cp
            ))

        # 3. Detect Major Eval Spike (|eval_delta| >= 100cp)
        ELSE IF ABS(eval_delta_cp) >= 100:
            self.key_past_events.append(HistoricEventModel(
                move_number = (ply_index // 2) + 1,
                ply = ply_index,
                player_color = board.turn,
                move_san = move_san,
                event_type = "major_eval_spike",
                description = f"Evaluation shifted by {eval_delta_cp}cp after {move_san}",
                eval_delta_cp = eval_delta_cp
            ))

        # 4. Update Persistent Imbalances
        UPDATE_IMBALANCES(self.persistent_imbalances, fen_after)
```

### 10.2 Anti-Hallucination Verification Pipeline (Post-Generation AST Check)

```
FUNCTION verify_llm_output_against_hallucinations(llm_response_text, legal_moves_san, pv_line_san):
    # 1. Extract all chess SAN move tokens from text using Regex
    # Regex captures strings like Nf3, Qxd5, O-O, e4, exf6, etc.

    RETURN True, "PASSED"
```

If the filter fails, the system automatically triggers a **Retry Request** to the LLM with a penalty prompt: *"Your previous response cited move {X} which is illegal/invalid in this position. Regenerate using ONLY valid moves: {valid_move_pool}."*

## 13. ERROR HANDLING, EDGE CASES & FAILURE MODES

### 13.1 Edge Case Catalog & Handling Mandates

1. **In-Check Null-Move Prohibition:**
   * *Scenario:* Player is in check. Executing `chess.Move.null()` raises `ValueError` in `python-chess`.
   * *Mandate:* Layer 2 MUST check `if board.is_check():` before attempting Null-Move threat detection. If in check, return empty concrete threats list or evaluate check escapes explicitly.
2. **Terminal Game States (Checkmate / Stalemate):**
   * *Scenario:* Move produces Checkmate or Stalemate. Stockfish score returns `mate 0` or `cp 0`.
   * *Mandate:* Skip Null-Move analysis. Set `eval_type="mate"`, `value=0`. Inject explicit `is_checkmate=True` / `is_stalemate=True` flag into Layer 4 payload.
3. **Underpromotions (e.g., Pawn to Knight/Rook/Bishop):**
   * *Scenario:* Move is `e7e8n`.
   * *Mandate:* Layer 2 must explicitly record promotion piece type and evaluate if promotion created a fork or knight check.
4. **Stockfish Subprocess Crash / Timeout:**
   * *Scenario:* Engine crashes or freezes due to memory exhaustion.
   * *Mandate:* Subprocess wrapper must implement a 5-second hard timeout per command. If process dies, auto-restart process, flush buffer, and retry query once. If second failure, throw `EngineDeadlockException`.
5. **LLM API Rate Limiting / 5xx Errors:**
   * *Scenario:* OpenAI/Anthropic API returns HTTP 429 or 503.
   * *Mandate:* Implement exponential backoff with jitter (retries: 4, backoff factors: 1s, 2s, 4s, 8s). If all retries fail, fallback to a local deterministic template-based explanation generator (`FallbackTemplateEngine`).
