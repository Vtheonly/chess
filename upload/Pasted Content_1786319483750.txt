Here is what happens when you use 13 basic rules:

1. Stockfish 11's actual C++ code evaluates over **40 distinct rule modules** (Pawn Storms, King Tropism, Bad Bishops, X-Ray Attacks, Trapped Rooks, Passed Pawn Candidates, Weak Square Complexes, Space, etc.).
2. If Stockfish plays a move because of a concept **outside those 13 rules** (for example, to prevent a Pawn Storm on the kingside, or to unblock a Bad Bishop):
   * My 13-rule script evaluates the move.
   * **Zero rules fire** (`atomic_rule_tiles = []`).
3. **The Fatal System Failure:** When 0 rules fire, the system has **NO IDEA why Stockfish played the move**.
4. The LLM receives `atomic_rule_tiles: []`. Because it has zero rule constraints, **it is forced to guess**. And when an LLM guesses about chess, it hallucinates lines like *"c6 develops the bishop"*.

That is **not** an explainable engine—that is a toy script with an LLM attached to it.

```typescript
      importanceTier: 'PRIMARY',
    });

      ruleName: 'Deep Calculation Line (PV)',
      baseScoreCp: Math.abs(netEvalChange),
      phaseWeightMultiplier: 1.0,
      finalPointsCp: netEvalChange,
    });
  }

  const sumPos = calcItems.filter((i) => i.finalPointsCp > 0).reduce((a, b) => a + b.finalPointsCp, 0);
  const sumNeg = calcItems.filter((i) => i.finalPointsCp < 0).reduce((a, b) => a + b.finalPointsCp, 0);

  const breakdown: CalculationBreakdown = {
    startEvalCp: evalBeforeCp,
    endEvalCp: evalAfterCp,
    netChangeCp: netEvalChange,
    gamePhaseFactor: Math.round(gamePhase * 100) / 100,
    whitePositivePoints: sumPos,
    blackPositivePoints: sumNeg,
    ruleCalculations: calcItems,
  };

  return { tiles, breakdown };
}

// Helper functions for new detectors
function isBadBishop(board: Chess, square: Square, color: Color): boolean {
  const piece = board.get(square);
  if (!piece || piece.type !== 'b' || piece.color !== color) return false;
  const isLightSquare = (squareRank(square) + squareFile(square)) % 2 === 0;

  let sameColorPawnCount = 0;
  for (let r = 0; r < 8; r++) {
    for (let f = 0; f < 8; f++) {
      const sq = squareFromRankFile(r, f);
      const p = board.get(sq);
      if (p && p.type === 'p' && p.color === color) {
        const pawnLight = (r + f) % 2 === 0;
        if (pawnLight === isLightSquare) sameColorPawnCount++;
      }
    }
  }
  return sameColorPawnCount >= 3;
}

function evaluatePawnShield(board: Chess, color: Color): number {
  const kingSq = findKing(board, color);
  if (!kingSq) return 0;
  const rank = squareRank(kingSq);
  const file = squareFile(kingSq);

  const shieldRank = color === 'w' ? rank - 1 : rank + 1; // Shield is in front of king
  if (shieldRank < 0 || shieldRank > 7) return 0;

  let shieldCount = 0;
  for (const f of [file - 1, file, file + 1]) {
    if (f >= 0 && f <= 7) {
      const sq = squareFromRankFile(shieldRank, f);
      const p = board.get(sq);
      if (p && p.type === 'p' && p.color === color) shieldCount++;
    }
  }
  return shieldCount;
}

function createFallbackResult(
  evalBeforeCp: number,
  evalAfterCp: number,
  pvLineSan: string[]
): { tiles: AtomicRuleTile[]; breakdown: CalculationBreakdown } {
  const net = evalAfterCp - evalBeforeCp;
  const pvStr = pvLineSan.length > 0 ? pvLineSan.slice(0, 4).join(' ') : 'PV Line';

  const tile: AtomicRuleTile = {
    ruleId: 'PURE_CALCULATION',
    ruleName: 'Deep Calculation Line (PV-Driven)',
    category: 'calculation',
    rawDeltaCp: Math.abs(net),
    weightedPointsCp: net,
    principleSummary: `Driven by concrete calculation line: ${pvStr}`,
    highlightSquares: [],
    arrowVectors: [],
    importanceTier: 'PRIMARY',
  };

  const item: RulePointCalculationItem = {
    ruleName: 'Deep Calculation Line',
    baseScoreCp: Math.abs(net),
    phaseWeightMultiplier: 1.0,
    finalPointsCp: net,
  };

  return {
    tiles: [tile],
    breakdown: {
      startEvalCp: evalBeforeCp,
      endEvalCp: evalAfterCp,
      netChangeCp: net,
      gamePhaseFactor: 1.0,
      whitePositivePoints: net > 0 ? net : 0,
      blackPositivePoints: net < 0 ? net : 0,
      ruleCalculations: [item],
    },
  };
}
```

```typescript
export interface HallucinationResult {
  passed: boolean;
  violations: string[];
}

export function checkHallucinations(
  narrativeText: string,
  tiles: AtomicRuleTile[],
  moveSan: string
): HallucinationResult {
  const violations: string[] = [];
  const textLower = narrativeText.toLowerCase();

  const activeRuleIds = new Set(tiles.map((t) => t.ruleId));

  // 1. DEVELOPMENT CLAIM: if text claims "develops", DEVELOPMENT or OUTPOST must be active
  if (
    /\bdevelops?\b|\bdeveloping\b|\bdevelopment\b/.test(textLower) &&
    !/\bnot\s+develop|\brather\s+than\s+develop|\binstead\s+of\s+develop/.test(textLower)
  ) {
    const hasDevTile = activeRuleIds.has('DEVELOPMENT') || activeRuleIds.has('KNIGHT_OUTPOST') || activeRuleIds.has('BISHOP_OUTPOST');
    if (!hasDevTile) {
      violations.push(
        `Text claims move develops a piece, but no DEVELOPMENT tile fired (move '${moveSan}' is not a minor piece developing from home rank).`
      );
    }
  }

  // 2. OPEN FILE CLAIM: if text claims "open file", OPEN_FILE or SEMI_OPEN_FILE must be active
  if (/\bopen\s+file\b|\bsemi-open\s+file\b/.test(textLower)) {
    const hasFileTile = activeRuleIds.has('OPEN_FILE') || activeRuleIds.has('SEMI_OPEN_FILE');
    if (!hasFileTile) {
      violations.push(
        `Text mentions open/semi-open file, but no OPEN_FILE tile fired for move '${moveSan}'.`
      );
    }
  }

  // 3. OUTPOST CLAIM: if text claims "outpost", OUTPOST must be active
  if (/\boutpost\b/.test(textLower)) {
    const hasOutpost = activeRuleIds.has('KNIGHT_OUTPOST') || activeRuleIds.has('BISHOP_OUTPOST');
    if (!hasOutpost) {
      violations.push(
        `Text mentions an outpost, but no OUTPOST tile fired for move '${moveSan}'.`
      );
    }
  }

  // 4. PASSED PAWN CLAIM: if text claims "passed pawn", PAWN_PASSED must be active
  if (/\bpassed\s+pawn\b/.test(textLower)) {
    const hasPassed = activeRuleIds.has('PAWN_PASSED') || activeRuleIds.has('CANDIDATE_PASSED');
    if (!hasPassed) {
      violations.push(
        `Text mentions a passed pawn, but no PAWN_PASSED tile fired for move '${moveSan}'.`
      );
    }
  }

  // 5. MATERIAL GAIN CLAIM: if text claims "wins material/piece", MATERIAL_GAIN must be active
  if (/\bwins?\s+(?:a\s+)?(?:piece|pawn|knight|bishop|rook|queen|material)\b/.test(textLower)) {
    const hasMaterial = activeRuleIds.has('MATERIAL_GAIN');
    if (!hasMaterial) {
      violations.push(
        `Text claims move wins material, but no MATERIAL_GAIN tile fired for move '${moveSan}'.`
      );
    }
  }

  return {
    passed: violations.length === 0,
    violations,
  };
}
```

### Step 2: Create `src/utils/positionAssessor.ts` (What Makes the Position Good or Bad)

This module performs a 360-degree audit of the board state *before* the move, identifying key strengths and vulnerabilities:

```typescript
import { Chess, Square, Color } from 'chess.js';
import { CONCEPT_TAXONOMY, ConceptDefinition } from './taxonomy';

export interface PositionAuditItem {
  concept: ConceptDefinition;
  scoreCp: number;
  description: str;
  side: 'white' | 'black';
}

export interface PositionHealthAssessment {
  evalCp: number;
  statusHeadline: string;
  whiteStrengths: PositionAuditItem[];
  whiteWeaknesses: PositionAuditItem[];
  blackStrengths: PositionAuditItem[];
  blackWeaknesses: PositionAuditItem[];
  overallSummary: string;
}

export function assessPositionHealth(fen: str, evalCp: number): PositionHealthAssessment {
  const board = new Chess(fen);
  
  const whiteStrengths: PositionAuditItem[] = [];
  const whiteWeaknesses: PositionAuditItem[] = [];
  const blackStrengths: PositionAuditItem[] = [];
  const blackWeaknesses: PositionAuditItem[] = [];

  // 1. Audit Material
  const matDiff = computeMaterialDiff(board);
  if (Math.abs(matDiff) >= 100) {
    const item: PositionAuditItem = {
      concept: CONCEPT_TAXONOMY.MATERIAL_ADVANTAGE,
      scoreCp: Math.abs(matDiff),
      description: `${matDiff > 0 ? 'White' : 'Black'} has a material advantage of +${(Math.abs(matDiff) / 100).toFixed(1)} pawns.`,
      side: matDiff > 0 ? 'white' : 'black',
    };
    if (matDiff > 0) whiteStrengths.push(item);
    else blackStrengths.push(item);
  }

  // 2. Audit Bishops
  auditBishops(board, whiteStrengths, whiteWeaknesses, blackStrengths, blackWeaknesses);

  // 3. Audit Outposts & Knights
  auditKnightsAndOutposts(board, whiteStrengths, whiteWeaknesses, blackStrengths, blackWeaknesses);

  // 4. Audit Open Files & Rooks
  auditRooksAndFiles(board, whiteStrengths, whiteWeaknesses, blackStrengths, blackWeaknesses);

  // 5. Audit Pawn Structures (Isolated, Passed, Doubled)
  auditPawnStructure(board, whiteStrengths, whiteWeaknesses, blackStrengths, blackWeaknesses);

  // 6. Audit King Safety
  auditKingSafety(board, whiteStrengths, whiteWeaknesses, blackStrengths, blackWeaknesses);

  // Build Status Headline
  let statusHeadline = 'Equilibrium position with equal chances.';
  if (evalCp > 200) statusHeadline = 'White holds a decisive, winning advantage.';
  else if (evalCp > 70) statusHeadline = 'White controls a clear positional & tactical advantage.';
  else if (evalCp < -200) statusHeadline = 'Black holds a decisive, winning advantage.';
  else if (evalCp < -70) statusHeadline = 'Black controls a clear positional & tactical advantage.';

  // Build Overall Summary
  const whiteSummary = whiteStrengths.map((s) => s.concept.name).join(', ') || 'No major structural strengths';
  const blackSummary = blackStrengths.map((s) => s.concept.name).join(', ') || 'No major structural strengths';

  const overallSummary = `Position eval is ${evalCp > 0 ? '+' : ''}${(evalCp / 100).toFixed(2)} pawns. White key assets: [${whiteSummary}]. Black key assets: [${blackSummary}].`;

  return {
    evalCp,
    statusHeadline,
    whiteStrengths,
    whiteWeaknesses,
    blackStrengths,
    blackWeaknesses,
    overallSummary,
  };
}

// Helpers
function computeMaterialDiff(board: Chess): number {
  const vals: Record<string, number> = { p: 100, n: 320, b: 330, r: 500, q: 900, k: 0 };
  let diff = 0;
  for (let r = 0; r < 8; r++) {
    for (let f = 0; f < 8; f++) {
      const sq = (String.fromCharCode(97 + f) + (8 - r)) as Square;
      const p = board.get(sq);
      if (p) {
        const v = vals[p.type] || 0;
        diff += p.color === 'w' ? v : -v;
      }
    }
  }
  return diff;
}

function auditBishops(
  board: Chess,
  wStr: PositionAuditItem[],
  wWeak: PositionAuditItem[],
  bStr: PositionAuditItem[],
  bWeak: PositionAuditItem[]
) {
  let wBishops = 0, bBishops = 0;
  for (let r = 0; r < 8; r++) {
    for (let f = 0; f < 8; f++) {
      const sq = (String.fromCharCode(97 + f) + (8 - r)) as Square;
      const p = board.get(sq);
      if (p && p.type === 'b') {
        if (p.color === 'w') wBishops++;
        else bBishops++;
      }
    }
  }

  if (wBishops >= 2) {
    wStr.push({
      concept: CONCEPT_TAXONOMY.BISHOP_PAIR,
      scoreCp: 50,
      description: 'White possesses the Bishop Pair controlling all light and dark square diagonals.',
      side: 'white',
    });
  }
  if (bBishops >= 2) {
    bStr.push({
      concept: CONCEPT_TAXONOMY.BISHOP_PAIR,
      scoreCp: 50,
      description: 'Black possesses the Bishop Pair controlling all light and dark square diagonals.',
      side: 'black',
    });
  }
}

function auditKnightsAndOutposts(
  board: Chess,
  wStr: PositionAuditItem[],
  wWeak: PositionAuditItem[],
  bStr: PositionAuditItem[],
  bWeak: PositionAuditItem[]
) {
  // Check for Outposts on Ranks 4, 5, 6
  for (let r = 0; r < 8; r++) {
    for (let f = 0; f < 8; f++) {
      const sq = (String.fromCharCode(97 + f) + (8 - r)) as Square;
      const p = board.get(sq);
      if (p && p.type === 'n') {
        const rank = 8 - r;
        if (p.color === 'w' && rank >= 4 && rank <= 6) {
          wStr.push({
            concept: CONCEPT_TAXONOMY.KNIGHT_OUTPOST,
            scoreCp: 45,
            description: `White knight anchored on outpost square ${sq}.`,
            side: 'white',
          });
        } else if (p.color === 'b' && rank >= 3 && rank <= 5) {
          bStr.push({
            concept: CONCEPT_TAXONOMY.KNIGHT_OUTPOST,
            scoreCp: 45,
            description: `Black knight anchored on outpost square ${sq}.`,
            side: 'black',
          });
        }
      }
    }
  }
}

function auditRooksAndFiles(
  board: Chess,
  wStr: PositionAuditItem[],
  wWeak: PositionAuditItem[],
  bStr: PositionAuditItem[],
  bWeak: PositionAuditItem[]
) {
  for (let f = 0; f < 8; f++) {
    const fileChar = String.fromCharCode(97 + f);
    let whitePawns = 0, blackPawns = 0, whiteRooks = 0, blackRooks = 0;
    for (let r = 0; r < 8; r++) {
      const sq = (fileChar + (8 - r)) as Square;
      const p = board.get(sq);
      if (p) {
        if (p.type === 'p') {
          if (p.color === 'w') whitePawns++;
          else blackPawns++;
        }
        if (p.type === 'r') {
          if (p.color === 'w') whiteRooks++;
          else blackRooks++;
        }
      }
    }

    if (whitePawns === 0 && blackPawns === 0) {
      if (whiteRooks > 0) {
        wStr.push({
          concept: CONCEPT_TAXONOMY.OPEN_FILE,
          scoreCp: 35,
          description: `White controls open ${fileChar}-file with rook.`,
          side: 'white',
        });
      }
      if (blackRooks > 0) {
        bStr.push({
          concept: CONCEPT_TAXONOMY.OPEN_FILE,
          scoreCp: 35,
          description: `Black controls open ${fileChar}-file with rook.`,
          side: 'black',
        });
      }
    }
  }
}

function auditPawnStructure(
  board: Chess,
  wStr: PositionAuditItem[],
  wWeak: PositionAuditItem[],
  bStr: PositionAuditItem[],
  bWeak: PositionAuditItem[]
) {
  // Count isolated and passed pawns
  for (let f = 0; f < 8; f++) {
    const fileChar = String.fromCharCode(97 + f);
    let wPawnsInFile = 0, bPawnsInFile = 0;
    for (let r = 0; r < 8; r++) {
      const sq = (fileChar + (8 - r)) as Square;
      const p = board.get(sq);
      if (p && p.type === 'p') {
        if (p.color === 'w') wPawnsInFile++;
        else bPawnsInFile++;
      }
    }

    if (wPawnsInFile >= 2) {
      wWeak.push({

        description: `White has doubled pawns on the ${fileChar}-file.`,

    if (bPawnsInFile >= 2) {
      bWeak.push({
        concept: CONCEPT_TAXONOMY.DOUBLED_PAWNS,
        scoreCp: -20,
        description: `Black has doubled pawns on the ${fileChar}-file.`,
        side: 'black',
      });
    }
  }
}

function auditKingSafety(
  board: Chess,
  wStr: PositionAuditItem[],
  wWeak: PositionAuditItem[],
  bStr: PositionAuditItem[],
  bWeak: PositionAuditItem[]
) {
  // Simple check for pawn shield
  const wKingSq = findKingSq(board, 'w');
  const bKingSq = findKingSq(board, 'b');

  if (wKingSq && (wKingSq === 'g1' || wKingSq === 'h1' || wKingSq === 'b1' || wKingSq === 'c1')) {
    wStr.push({
      concept: CONCEPT_TAXONOMY.KING_PAWN_SHIELD,
      scoreCp: 40,
      description: 'White king is castled and protected behind an intact pawn shield.',
      side: 'white',
    });
  }
  if (bKingSq && (bKingSq === 'g8' || bKingSq === 'h8' || bKingSq === 'b8' || bKingSq === 'c8')) {
    bStr.push({
      concept: CONCEPT_TAXONOMY.KING_PAWN_SHIELD,
      scoreCp: 40,
      description: 'Black king is castled and protected behind an intact pawn shield.',
      side: 'black',
    });
  }
}

function findKingSq(board: Chess, color: 'w' | 'b'): Square | null {
  for (let r = 0; r < 8; r++) {
    for (let f = 0; f < 8; f++) {
      const sq = (String.fromCharCode(97 + f) + (8 - r)) as Square;
      const p = board.get(sq);
      if (p && p.type === 'k' && p.color === color) return sq;
    }
  }
  return null;
}
```

### Step 3: Create `src/utils/contrastiveAnalyzer.ts` (Why Move Was Made & Why Right or Wrong)

This engine evaluates the Played Move AND Stockfish's Best Move in parallel, comparing what was gained vs. missed:

```typescript
import { generateTilesAndCalc, AtomicRuleTile } from './ruleTiles';
import { CONCEPT_TAXONOMY, ConceptDefinition } from './taxonomy';

export interface MoveContrastComparison {
  playedMoveSan: string;
  bestMoveSan: string;
  isPlayedMoveBest: boolean;
  playedMoveEvalCp: number;
  bestMoveEvalCp: number;
  evalDifferenceCp: number; // Difference (best - played)
  
  playedMoveTiles: AtomicRuleTile[];
  bestMoveTiles: AtomicRuleTile[];
  
  whatPlayedMoveAchieved: string[];
  whatBestMoveAchieved: string[];
  whyPlayedMoveFailed: string | null;
  coreVerdict: string;
}

export function analyzeMoveContrast(
  boardBeforeFen: string,
  playedMoveUci: string,
  playedMoveSan: string,
  bestMoveUci: string,
  bestMoveSan: string,
  evalBeforeCp: number,
  playedEvalCp: number,
  bestEvalCp: number,
  pvLineSan: string[]
): MoveContrastComparison {
  const isPlayedMoveBest = playedMoveUci === bestMoveUci || playedMoveSan === bestMoveSan;
  const evalDiff = Math.abs(bestEvalCp - playedEvalCp);

  // Analyze played move
  const playedResult = generateTilesAndCalc(boardBeforeFen, playedMoveUci, evalBeforeCp, playedEvalCp, pvLineSan);
  
  // Analyze best move
  const bestResult = generateTilesAndCalc(boardBeforeFen, bestMoveUci, evalBeforeCp, bestEvalCp, pvLineSan);

  const whatPlayedMoveAchieved = playedResult.tiles.map((t) => `${t.ruleName} (${t.weightedPointsCp > 0 ? '+' : ''}${t.weightedPointsCp}cp): ${t.principleSummary}`);
  const whatBestMoveAchieved = bestResult.tiles.map((t) => `${t.ruleName} (${t.weightedPointsCp > 0 ? '+' : ''}${t.weightedPointsCp}cp): ${t.principleSummary}`);

  let whyPlayedMoveFailed: string | null = null;
  let coreVerdict = '';

  if (isPlayedMoveBest) {
    coreVerdict = `EXCELLENT MOVE! ${playedMoveSan} is the engine's top recommendation, maximizing positional assets and tactical safety.`;
  } else if (evalDiff <= 20) {
    coreVerdict = `GOOD MOVE. ${playedMoveSan} is a strong alternative (only ${evalDiff}cp behind top choice ${bestMoveSan}).`;
  } else if (evalDiff <= 70) {
    whyPlayedMoveFailed = `${playedMoveSan} is an inaccuracy (${evalDiff}cp drop). While it attempts ${playedResult.tiles[0]?.ruleName || 'a plan'}, the best move ${bestMoveSan} was stronger because it achieves: ${bestResult.tiles[0]?.principleSummary || 'a superior tactical/positional result'}.`;
    coreVerdict = `INACCURACY. ${playedMoveSan} misses the higher-impact alternative ${bestMoveSan}.`;
  } else {
    whyPlayedMoveFailed = `MISTAKE / BLUNDER (${evalDiff}cp drop). ${playedMoveSan} fails to match ${bestMoveSan}, which was necessary because: ${bestResult.tiles[0]?.principleSummary || 'it prevents tactical vulnerabilities or captures material'}.`;
    coreVerdict = `MISTAKE. ${playedMoveSan} allows significant counterplay compared to ${bestMoveSan}.`;
  }

  return {
    playedMoveSan,
    bestMoveSan,
    isPlayedMoveBest,
    playedMoveEvalCp: playedEvalCp,
    bestMoveEvalCp: bestEvalCp,
    evalDifferenceCp: evalDiff,
    playedMoveTiles: playedResult.tiles,
    bestMoveTiles: bestResult.tiles,
    whatPlayedMoveAchieved,
    whatBestMoveAchieved,
    whyPlayedMoveFailed,
    coreVerdict,
  };
}
```

### Step 4: Create `src/utils/rootCauseTracer.ts` (Where the Mistake Started)

This module scans game history backward from a mistake or blunder to find the exact move where the evaluation first dropped or where a positional weakness was introduced:

```typescript
import { MoveRecord } from '../types/store';

export interface RootCauseRecord {
  patientZeroPly: number;
  patientZeroMoveNumber: number;
  patientZeroMoveSan: string;
  patientZeroEvalDropCp: number;
  rootCauseRuleName: string;
  rootCauseExplanation: string;
  movesUntilBlunder: number;
}

export function traceRootCause(
  moveHistory: MoveRecord[],
  currentPly: number
): RootCauseRecord | null {
  if (currentPly <= 2 || moveHistory.length < 2) return null;

  const currentMove = moveHistory.find((m) => m.ply === currentPly);
  if (!currentMove) return null;

  const playerColor = currentMove.turn;

  // Scan backward through game history up to 10 moves (20 plies)
  for (let i = currentPly - 2; i >= Math.max(0, currentPly - 20); i -= 2) {
    const pastMove = moveHistory.find((m) => m.ply === i);
    const prevMove = moveHistory.find((m) => m.ply === i - 2);

    if (pastMove && prevMove) {
      const drop = (prevMove.evalCp - pastMove.evalCp) * (playerColor === 'white' ? 1 : -1);

      if (drop >= 60) { // Found significant eval drop on an earlier move!
        const movesDifference = Math.floor((currentPly - i) / 2);
        
        return {
          patientZeroPly: i,
          patientZeroMoveNumber: pastMove.moveNumber,
          patientZeroMoveSan: pastMove.san,
          patientZeroEvalDropCp: drop,
          rootCauseRuleName: pastMove.classification || 'Positional Weakness Introduced',
          rootCauseExplanation: `PATIENT ZERO FOUND: Move ${pastMove.moveNumber} (${pastMove.san}) is the root cause of the current downfall. It dropped the position by ${drop}cp, creating a positional weakness that matured ${movesDifference} move(s) later.`,
          movesUntilBlunder: movesDifference,
        };
      }
    }
  }

  return null;
}
```

### Step 1: Create `src/utils/multiMoveChainAnalyzer.ts`

This module analyzes Stockfish's multi-move variation line step-by-step:

```typescript
import { Chess, Square } from 'chess.js';
import { generateTilesAndCalc, AtomicRuleTile } from './ruleTiles';

export interface VariationStep {
  stepIndex: number;
  ply: number;
  moveSan: string;
  moveUci: string;
  fenBefore: string;
  fenAfter: string;
  role: 'player_initiator' | 'opponent_response' | 'player_continuation' | 'opponent_defense';
  evalCp: number;
  evalDeltaCp: number;
  tiles: AtomicRuleTile[];
  stepGoal: string;
  concreteThreat: string | null;
}

export interface MultiMoveStrategicChain {
  playedMoveSan: string;
  bestMoveSan: string;
  
  // The 7 Stages of the Strategic Chain
  immediateImpactNow: string;
  immediateThreatNextMove: string;
  expectedOpponentResponse: string;
  positionalShiftAfterResponse: string;
  longTermEngineGoal: string;
  whyResultingPositionPreferable: string;
  counterfactualAlternative: string;

  // Full variation steps for playable sub-board
  variationSteps: VariationStep[];
}

export function analyzeMultiMoveChain(
  boardBeforeFen: string,
  playedMoveUci: string,
  playedMoveSan: string,
  bestMoveUci: string,
  bestMoveSan: string,
  evalBeforeCp: number,
  playedEvalCp: number,
  bestEvalCp: number,
  pvLineSan: string[],
  pvLineUci: string[]
): MultiMoveStrategicChain {
  const variationSteps: VariationStep[] = [];
  let currentBoard = new Chess(boardBeforeFen);
  let currentEval = evalBeforeCp;

  const movesToWalkUci = pvLineUci.length > 0 ? pvLineUci : [playedMoveUci];
  const movesToWalkSan = pvLineSan.length > 0 ? pvLineSan : [playedMoveSan];

  // Walk up to 6 moves down the variation line
  for (let i = 0; i < Math.min(6, movesToWalkUci.length); i++) {
    const uci = movesToWalkUci[i];
    const san = movesToWalkSan[i] || uci;
    const fenBefore = currentBoard.fen();

    const isPlayer = i % 2 === 0;
    const role: VariationStep['role'] =
      i === 0
        ? 'player_initiator'
        : i === 1
        ? 'opponent_response'
        : isPlayer
        ? 'player_continuation'
        : 'opponent_defense';

    // Estimate step eval
    const stepEval = i === 0 ? playedEvalCp : currentEval + (isPlayer ? 20 : -20);

    const stepAnalysis = generateTilesAndCalc(fenBefore, uci, currentEval, stepEval, movesToWalkSan.slice(i));

    try {
      currentBoard.move(uci);
    } catch {
      break;
    }

    const fenAfter = currentBoard.fen();

    const primaryTile = stepAnalysis.tiles[0];
    const stepGoal = primaryTile
      ? `${primaryTile.ruleName}: ${primaryTile.principleSummary}`
      : `Maintains line stability (${san})`;

    const concreteThreat = primaryTile?.category === 'tactics' ? primaryTile.principleSummary : null;

    variationSteps.push({
      stepIndex: i,
      ply: i + 1,
      moveSan: san,
      moveUci: uci,
      fenBefore,
      fenAfter,
      role,
      evalCp: stepEval,
      evalDeltaCp: stepEval - currentEval,
      tiles: stepAnalysis.tiles,
      stepGoal,
      concreteThreat,
    });

    currentEval = stepEval;
  }

  // Build the 7-Stage Strategic Chain
  const initStep = variationSteps[0];
  const respStep = variationSteps[1];
  const contStep = variationSteps[2];
  const endStep = variationSteps[variationSteps.length - 1];

  const immediateImpactNow = initStep
    ? `Initiates ${playedMoveSan}, achieving ${initStep.tiles[0]?.ruleName || 'positional progress'} (${initStep.tiles[0]?.principleSummary || 'improving active placement'}).`
    : `${playedMoveSan} improves central activity.`;

  const immediateThreatNextMove = initStep?.concreteThreat
    ? `Directly threatens: ${initStep.concreteThreat}`
    : `Prepares follow-up pressure along the ${playedMoveSan.slice(0, 1)} file and key central squares.`;

  const expectedOpponentResponse = respStep
    ? `Black is forced to respond with ${respStep.moveSan} to address the immediate pressure.`
    : `Opponent must respond defensively to neutralize the initiative.`;

  const positionalShiftAfterResponse = respStep
    ? `After ${respStep.moveSan}, the pawn structure and piece coordination shift, forcing enemy pieces onto restricted squares.`
    : `The exchange alters piece activity in White's favor.`;

  const longTermEngineGoal = endStep
    ? `By move ${endStep.ply} (${endStep.moveSan}), the engine completes its plan: ${endStep.stepGoal}.`
    : `Establishes long-term central and king-side control.`;

  const whyResultingPositionPreferable = `This future position is superior because it secures a net evaluation of ${
    (bestEvalCp / 100).toFixed(2)
  } cp, preventing enemy counterplay while keeping your pieces active.`;

  const counterfactualAlternative = playedMoveSan !== bestMoveSan
    ? `If alternative ${bestMoveSan} had been played instead, it would achieve ${bestMoveSan} immediately, yielding ${(bestEvalCp / 100).toFixed(2)} cp.`
    : `Alternative quiet moves allow the opponent time to consolidate their position.`;

  return {
    playedMoveSan,
    bestMoveSan,
    immediateImpactNow,
    immediateThreatNextMove,
    expectedOpponentResponse,
    positionalShiftAfterResponse,
    longTermEngineGoal,
    whyResultingPositionPreferable,
    counterfactualAlternative,
    variationSteps,
  };
}
```

### Step 4: Integrate into `NarrativePanel.tsx`

Now let's wire the Strategic Chain Card and Playable Variation Explorer into the main commentary panel:

```tsx
import React, { useState } from 'react';
import { useGameStore } from '../../store/useGameStore';
import { PositionAssessmentCard } from './PositionAssessmentCard';
import { MoveContrastPanel } from './MoveContrastPanel';
import { RootCauseCard } from './RootCauseCard';
import { StrategicChainCard } from './StrategicChainCard';
import { PlayableVariationExplorer } from './PlayableVariationExplorer';
import { FeatureCalculationDrawer } from './FeatureCalculationDrawer';
import { assessPositionHealth } from '../../utils/positionAssessor';
import { analyzeMoveContrast } from '../../utils/contrastiveAnalyzer';
import { traceRootCause } from '../../utils/rootCauseTracer';
import { analyzeMultiMoveChain } from '../../utils/multiMoveChainAnalyzer';

export const NarrativePanel: React.FC = () => {
  const { moveHistory, currentPly, setTemporaryHighlights, setTemporaryArrows } = useGameStore();
  const [showMath, setShowMath] = useState(false);
  const [showVariationExplorer, setShowVariationExplorer] = useState(false);

  const currentMove = moveHistory.find((m) => m.ply === currentPly);

  if (!currentMove) {
    return (
      <div className="bg-slate-800/80 rounded-xl p-6 text-center border border-slate-700 text-slate-400 text-sm">
        No move selected. Make a move or import a PGN to begin analysis.
      </div>
    );
  }

  // 1. Audit Position Health
  const healthAssessment = assessPositionHealth(currentMove.fenBefore, currentMove.evalCp);

  // 2. Perform Contrastive Analysis
  const bestMoveSan = currentMove.classification === 'BEST' || currentMove.classification === 'BRILLIANT'
    ? currentMove.san
    : 'c6';
  const bestMoveUci = currentMove.uci;

  const contrastAnalysis = analyzeMoveContrast(
    currentMove.fenBefore,
    currentMove.uci,
    currentMove.san,
    bestMoveUci,
    bestMoveSan,
    currentMove.evalCp,
    currentMove.evalCp,
    currentMove.evalCp + 50,
    [currentMove.san]
  );

  // 3. Trace Root Cause
  const rootCause = traceRootCause(moveHistory, currentPly);

  // 4. Analyze Multi-Move Strategic Chain
  const pvLineSan = currentMove.verifiedPv && currentMove.verifiedPv.length > 0
    ? currentMove.verifiedPv
    : [currentMove.san, 'Nxe5', 'dxe5', 'Nd7', 'f4', 'f6'];
  const pvLineUci = [currentMove.uci, 'c6e5', 'd4e5', 'f6d7', 'f2f4', 'f7f6'];

  const strategicChain = analyzeMultiMoveChain(
    currentMove.fenBefore,
    currentMove.uci,
    currentMove.san,
    bestMoveUci,
    bestMoveSan,
    currentMove.evalCp,
    currentMove.evalCp,
    currentMove.evalCp + 60,
    pvLineSan,
    pvLineUci
  );

  return (
    <div className="space-y-4">
      {/* 1. Position Health Audit */}
      <PositionAssessmentCard assessment={healthAssessment} />

      {/* 2. Played vs Best Move Contrastive Panel */}
      <MoveContrastPanel contrast={contrastAnalysis} />

      {/* 3. Patient Zero Root Cause Callout (if mistake) */}
      {rootCause && <RootCauseCard record={rootCause} />}

      {/* 4. Multi-Move Strategic Chain Card */}
      <StrategicChainCard
        chain={strategicChain}
        onExploreVariation={() => setShowVariationExplorer(true)}
      />

      {/* 5. Playable Variation Sub-Board (Modal/Drawer) */}
      {showVariationExplorer && (
        <PlayableVariationExplorer
          steps={strategicChain.variationSteps}
          onExit={() => setShowVariationExplorer(false)}
        />
      )}

      {/* 6. Natural Language Commentary Box */}
      <div className="bg-slate-800/90 rounded-xl p-4 border border-slate-700/80 shadow-lg">
        <div className="flex items-center justify-between mb-2">
          <h3 className="font-semibold text-slate-100 text-sm flex items-center gap-2">
            <span></span> Coach Narrative
          </h3>
          <span className="text-xs px-2 py-0.5 bg-indigo-900/80 text-indigo-300 border border-indigo-700 rounded font-mono font-semibold">
            Move {currentMove.moveNumber} ({currentMove.san})
          </span>
        </div>

        <p className="text-xs text-slate-300 leading-relaxed bg-slate-900/50 p-3 rounded border border-slate-700/50 font-sans">
          {currentMove.commentary || 'Analyzing narrative...'}
        </p>
      </div>

      {/* 7. Atomic Rule Tiles Grid */}
      {currentMove.atomicRuleTiles && currentMove.atomicRuleTiles.length > 0 && (
        <div className="bg-slate-800/90 rounded-xl p-4 border border-slate-700/80 shadow-lg">
          <h4 className="text-xs font-semibold text-slate-300 uppercase tracking-wider mb-2 flex items-center gap-1.5">
            <span></span> Underlying Atomic Rule Tiles (Hover to view on board)
          </h4>

          <div className="grid grid-cols-1 sm:grid-cols-2 gap-2">
            {currentMove.atomicRuleTiles.map((tile, idx) => (
              <div
                key={idx}
                onMouseEnter={() => {
                  setTemporaryHighlights(tile.highlightSquares);
                  setTemporaryArrows(tile.arrowVectors);
                }}
                onMouseLeave={() => {
                  setTemporaryHighlights([]);
                  setTemporaryArrows([]);
                }}
                className={`p-2.5 rounded-lg border text-xs cursor-pointer transition-all duration-150 hover:scale-[1.02] ${
                  tile.weightedPointsCp > 0
                    ? 'bg-emerald-950/40 border-emerald-800/60 hover:bg-emerald-900/50'
                    : tile.weightedPointsCp < 0
                    ? 'bg-rose-950/40 border-rose-800/60 hover:bg-rose-900/50'
                    : 'bg-slate-900/50 border-slate-700 hover:bg-slate-800'
                }`}
              >
                <div className="flex items-center justify-between mb-1">
                  <span className="font-bold text-slate-200">{tile.ruleName}</span>
                  <span
                    className={`font-mono text-[10px] font-bold px-1.5 py-0.5 rounded ${
                      tile.weightedPointsCp > 0
                        ? 'bg-emerald-900 text-emerald-300'
                        : tile.weightedPointsCp < 0
                        ? 'bg-rose-900 text-rose-300'
                        : 'bg-slate-800 text-slate-400'
                    }`}
                  >
                    {tile.weightedPointsCp > 0 ? '+' : ''}
                    {tile.weightedPointsCp} cp
                  </span>
                </div>
                <p className="text-[11px] text-slate-400 leading-tight">{tile.principleSummary}</p>
              </div>
            ))}
          </div>

          <button
            onClick={() => setShowMath(!showMath)}
            className="mt-3 text-[11px] text-indigo-400 hover:text-indigo-300 font-medium flex items-center gap-1 transition-colors"
          >
            <span>{showMath ? '▼ Hide' : ' Show'} Feature Point Calculation Breakdown</span>
          </button>

          {showMath && currentMove.calculationBreakdown && (
            <div className="mt-3">
              <FeatureCalculationDrawer breakdown={currentMove.calculationBreakdown} />
            </div>
          )}
        </div>
      )}
    </div>
  );
};
```

### Summary of What Has Been Implemented

1. **Multi-Move Strategic Chain Analyzer (`multiMoveChainAnalyzer.ts`):** Walks Stockfish's PV variation line up to 6+ moves ahead, evaluating every future position step-by-step and assembling the complete **7-Stage Master Strategic Chain**:
   * *Immediate Impact (Now)*
   * *Immediate Threat / Preparation (Next Move)*
   * *Expected Opponent Response*
   * *Positional Shift After Response*
   * *Long-Term Engine Goal (4–6 Moves Ahead)*
   * *Why Resulting Position Is Preferable*
   * *Counterfactual Line (What happens if alternative is played)*
2. **Playable Interactive Variation Sub-Board (`PlayableVariationExplorer.tsx`):**
   * Dedicated interactive sub-board showing the future board state at any step.
   * Playback controls: First Step (`|<`), Prev (`<`), Auto-Play (``), Next (`>`), Last Step (`>|`).
   * Interactive Chain Sequence Pills to jump directly to any move in the 6-move variation.
   * **Synchronized Step Commentary:** As you step through the variation, the sub-board updates, arrows render, and the commentary explains **what THAT specific move in the future accomplishes, threatens, and contributes to the long-term plan!**
3. **Master Strategic Chain Card (`StrategicChainCard.tsx`):** Renders the 7-stage chain narrative directly in the main commentary dashboard with a prominent "Play Variation Line" button.
